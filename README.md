# 🏯 사방신 무림전 (四方神 武林傳) - 1v1 룸 코드 멀티플레이어

HTML5 Canvas, WebRTC DataChannel(PeerJS), 순수 Modern JavaScript로 제작된 **2D 동양 수묵화 1v1 온라인 대전 격투 게임**입니다.

별도의 복잡한 백엔드 서버 설치 없이 **6자리 방 코드(Room Code)** 입력만으로 두 플레이어 간 P2P 실시간 1v1 무협 대전이 가능합니다.

---

## 🌐 1v1 온라인 멀티플레이 대전 방법

### 1. 방 만들기 (Host)
1. [`index.html`](./index.html)을 실행하고 원하는 사방신 고수를 선택합니다.
2. 하단의 **[방 만들기]** 버튼을 클릭합니다.
3. 생성된 **6자리 룸 코드**(예: `A7X9P2`)를 **[코드 복사]** 버튼을 눌러 대전할 상대방에게 메신저 등으로 전달합니다.
4. 상대방이 입장하면 즉시 사계절 무림 투기장 중 하나가 무작위로 열리며 1v1 온라인 결전이 시작됩니다!

### 2. 방 참가하기 (Guest)
1. 브라우저에서 게임을 열고 원하는 사방신 고수를 선택합니다.
2. 하단의 **[방 참가하기]** 버튼을 클릭합니다.
3. 상대방에게 전달받은 **6자리 룸 코드**를 입력하고 **[참가하기]**를 누르면 즉시 동기화되어 결전이 시작됩니다.

### 3. 연습 모드 (혼자 하기)
- **[혼자 연습 (vs AI)]**을 누르면 상대방 연결 없이 혼자서 자유롭게 기술 콤보와 궁극기 연출을 연습해볼 수 있습니다.

## 🕹️ 1P 공통 무공 조작계 (모든 플레이어 동일)

두 플레이어 모두 각자의 화면에서 표준 1P 키를 동일하게 사용합니다:

| 키 | 액션 | 상세 설명 |
| :---: | :---: | :--- |
| **A / D** | **좌우 보법 이동** | 고속 이동 시 먹빛 잔상 대시 발생 |
| **W** | **도약 (점프)** | 공중 도약 *(주작은 공중 2단 도약 가능)* |
| **S** | **숙이기 / 수경 방어** | 대미지 80% 경감 및 가드 스파크 발생 |
| **J** | **기본 공격 연타** | 3연격 무술 콤보 및 붓터치 검격 궤적 |
| **K** | **무기 특수기** | 기력(SP) 25 소모 / 사방신 전용 무공 사출 |
| **L** | **사방신 궁극기** | 기력(SP) 100% 시 시전 / **화면 줌인 컷씬** 연출 |

## 🌸 사계절 무림 투기장 (Seasonal Arenas)
룸 입장 시 사계절 중 하나가 무작위로 선택됩니다:
1. **봄 - 낙화유수 (落花流水)**: 은은한 분홍빛 보름달과 바람에 흩날리는 벚꽃잎
2. **여름 - 청죽녹음 (靑竹綠陰)**: 시원한 대나무 숲과 흩날리는 죽엽, 반딧불이
3. **가을 - 만산홍엽 (滿山紅葉)**: 붉게 물든 단풍 산세와 휘몰아치는 붉은 단풍잎
4. **겨울 - 설산빙벽 (雪山氷壁)**: 휘몰아치는 설산과 하얗게 흩날리는 함박눈

---

## ⚔️ 4인의 사방신 무림 고수

1. **청룡 (靑龍 - 청도검객)**: 청록색 비단 도포. 날렵한 청룡검과 풍압 검기 사출, 화면을 가르는 초고속 십자 난무.
2. **백호 (白虎 - 패도전사)**: 묵직한 중갑주. 거대한 백호대도로 적의 방어를 부수는 가드 브레이크, 대지 분쇄 포효.
3. **주작 (朱雀 - 불멸의 선무가)**: 진홍빛 날개 도포. 공중 2단 도약과 주작철선(부채) 화염 탄막 폭격.
4. **현무 (玄武 - 심연의 흑도사)**: 짙은 먹빛 도포. 현무사슬낫으로 적을 제압하고 끌어당기며, 수경 반격으로 카운터.
